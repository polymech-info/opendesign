Polymech / OpenDesign

Open-source canvas editor for design stills

Polymech publishes OpenDesign for app-store screenshots and other fixed-size stills. Open a canvas in the browser, place type and shapes, and download a PNG. The design stays on this device.

Open the editor OpenDesign source on GitHub

Compose a still

The canvas is a fixed page, the size of a store screenshot or a feature card. Add headings, body text, rectangles, circles, and lines. Drop an image onto the page and it is stored with the design. Undo, layers, and snap guides are in the editor.

Pages and versions

A design can hold more than one page. Saving keeps an autosave you can restore from the versions list. PNG and JSON both download in the browser.

Starter designs

The first visit creates Quote Card and Stats Highlight in this browser, and the template list includes those layouts. Creating from a template makes a new design and leaves the one you have open alone.

Designs stay in this browser

Designs and uploaded images are saved in the browser’s private file storage for this site. Nothing from the canvas is uploaded to Polymech. The next visit on the same browser still has them. Another browser, or a private window that blocks that storage, starts again from the two starter designs.

The hosted editor and the local app

This page runs the canvas in the browser. Chat, the icon library, and saving a PNG into a project folder belong to the local app, pm-opendesign, which stores designs in a folder on your machine.

Source

The editor is MIT licensed in the OpenDesign repository on GitHub. It is part of the open-source tools Polymech publishes while building manufacturing software.
